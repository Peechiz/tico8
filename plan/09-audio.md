# 09 — Audio

## Demo

`examples/08-animation` grows sound: a `sounds` folder with a swing effect
and a looping theme. The attack plays the swing, overlapping when pressed
fast, and the theme starts on the first key press and loops at a lower
volume. Saving `main.ts` restarts the game without restarting the theme.
Saving a sound file swaps it in the running game.

## Spec

`01-spec.md`: Sound.

## Decided

- **One kind of thing:** music is a sound played with `loop: true`.
- **Effects overlap; a loop has one copy,** so playing it again does nothing.
- **Volume per sound** (`theme.volume`, and `{ volume }` on one play); a
  master volume for the pause menu that games cannot reach.
- **Before the first key press, click or tap:** effects are dropped, loops
  wait and start on it.
- **A code restart keeps loops the new game plays again,** stops the rest.
- **wav, ogg and mp3.**
- **The demo grows example 08,** at the user's choice.

## Layout

```
packages/tico8/src/audio/types.ts    Sound, and the slice of Web Audio the mixer uses
packages/tico8/src/audio/mixer.ts    sounds over decoded clips: copies, loops, volume, unlock, restart
packages/tico8/src/audio/web.ts      that slice of Web Audio, over a real AudioContext
packages/tico8/src/audio/unlock.ts   the first key press, click or tap
packages/tico8/src/assets/sounds.ts  the console's sounds by address: load, decode, swap
packages/tico8/src/vite/sounds.ts    the generated sounds.ts
packages/tico8/src/vite/assets-hmr.ts  tells the page a sound file changed
```

How a sound reaches a game: the dev tool writes `sounds.ts`, which calls
`sound` from `tico8/assets` with each file's address. The page fetches and
decodes every sound before `init`, as it loads every sheet. The mixer
never touches the browser itself; it drives an `AudioOut`, so tests give it
a fake one.

The generated file, exactly:

```ts
// Generated by tico8 from the sounds folder. Do not edit.
import { sound } from 'tico8/assets'

export const swing = sound('/sounds/swing.wav')
export const theme = sound('/sounds/theme.ogg')
```

How loudly a copy plays: the master volume, times its sound's `volume`,
times the `volume` given to its `play`. Changing either of the first two
changes copies already sounding.

  `AudioOut`, `Clip`, `Voice`, `Mixer` and `LoadableSound`; the signature

  Owns: `src/audio/types.ts`, `src/assets/event.ts`, the declarations in
  every file below. Waits on: none.
- [ ] **2. Mixer.** `createMixer(out)`: one-off copies overlap; a loop has
  one copy and playing it again only takes the new per-play volume; `stop`
  stops every copy; volume as under "Layout", applied to copies sounding;
  `playing`; before `unlock` effects are dropped and loops wait, starting on
  `unlock`; `restarting` stops effects and marks loops, `settle` stops the
  loops not played since; `setClip` swaps a sound's clip and starts a loop
  under way again with it; a sound with no clip plays nothing.
  Owns: `src/audio/mixer.ts`, `src/audio/mixer.test.ts`. Waits on: 1.
- [ ] **3. Browser audio.** `createWebAudio()`: an `AudioOut` over one
  `AudioContext`, with a gain node per copy and one for the master volume.
  `attachUnlock(target, unlock)`: calls `unlock` once on the first
  `keydown`, `pointerdown` or `touchend`, then stops listening; returns a
  function that stops listening early.
  Owns: `src/audio/web.ts`, `src/audio/unlock.ts`,
  `src/audio/unlock.test.ts`. Waits on: 1.
- [ ] **4. Loading and live swap.** `createSounds` keeps a console's sounds
  by address: `sound(url)` hands back a sound at once and fetches and
  decodes its file, trying a file that will not load once more; asked for
  the same address again (the generated file re-run), it hands back the
  same sound, so a loop under way is still its own; `ready`
  settles when all have loaded; `reload` fetches a changed file past the
  browser's cache and swaps it in, keeping the old one if it will not
  decode. A file that cannot be used is reported in the console and its
  sound plays nothing. The page listens for the change event.
  Owns: `src/assets/sounds.ts`, `src/assets/sounds.test.ts`. Waits on: 1.

  Owns: `src/vite/sounds.ts`, `src/vite/sounds.test.ts`. Waits on: 1.
- [ ] **6. Change events.** Saving a sound file sends its address to the
